# AAIF Helsinki Hackathon

**AAIF (formerly MLOps) Community Helsinki #12: Real-World Business AI Hackathon**
Haaga-Helia University of Applied Sciences, Pasila campus, Helsinki · [Event page](https://luma.com/eizq457i)

Teams build AI agents for real-world business process automation, using business process models and open source assets such as the [GAIK toolkit](https://github.com/GAIK-project/gaik-toolkit).

## For teams

- Create one repository per team in this organization and add your teammates.
- Keep secrets, API keys and confidential business data out of public repositories.
- Show your result in the demo session and share the repo link in `#demos` on Discord.

## Resources

- GAIK toolkit: https://github.com/GAIK-project/gaik-toolkit (`pip install gaik`)
- Docs: https://gaik-project.github.io/gaik-toolkit/
